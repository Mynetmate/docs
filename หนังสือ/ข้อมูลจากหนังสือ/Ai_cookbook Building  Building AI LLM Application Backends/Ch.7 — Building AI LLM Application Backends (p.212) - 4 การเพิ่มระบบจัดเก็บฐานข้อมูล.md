### **7.3 Adding database storage (การเพิ่มระบบจัดเก็บฐานข้อมูล)**

แอปพลิเคชันส่วนใหญ่จำเป็นต้องมีการบันทึกข้อมูลเก็บไว้ (Persist information) ในหัวข้อนี้เราจะเพิ่มฐานข้อมูล **SQLite** เข้ามาในระบบเพื่อใช้เก็บบันทึกบทสนทนา ซึ่งจะช่วยให้เรารู้ว่า User มักจะเข้ามาถามคำถามแนวไหน และยังทำให้แอปฯ ของเรามีระบบ "ประวัติการแชท (Conversation history)" ด้วย

ต้องเขียนโค้ดจากหัวข้อที่แล้วให้เสร็จก่อนจึงจะไปต่อได้

### **How to do it… (ขั้นตอนการทำ)**

1. ก๊อปปี้ไฟล์เดิมมาสร้างเป็นไฟล์ใหม่ชื่อ `main_v3.py`
2. อิมพอร์ตไลบรารี **SQLAlchemy** (ซึ่งเป็นเครื่องมือยอดฮิตของ Python ในการจัดการ Database)
3. **ตั้งค่า Database:** สร้างคำสั่งเชื่อมต่อกับไฟล์ `questions.db` (เครื่องยนต์กลไก) และสร้างตัวแปร `Session` สำหรับจัดการการดึง/บันทึกข้อมูล
4. **สร้าง Model ฐานข้อมูล:** สร้างคลาสชื่อ `Question` เพื่อกำหนดตารางข้อมูล (Table) ว่าเราจะเก็บอะไรบ้าง:
    - `id`: ตัวเลขรหัสคำถาม (รันออโต้)
    - `question`: คำถามของ User
    - `answer`: คำตอบของ AI
    - `device_type`: ยี่ห้ออุปกรณ์
    - `timestamp`: เวลาที่ถาม (ระบบบันทึกให้อัตโนมัติ ณ วินาทีนั้น)
5. ใส่คำสั่ง `Base.metadata.create_all(engine)` ซึ่งมันจะฉลาดพอที่จะ **"สร้างตารางเปล่าขึ้นมาให้เองอัตโนมัติ"** ถ้ามันยังไม่มีตารางนี้อยู่
6. นำคำสั่งไปแทรกไว้ในฟังก์ชัน `/ask` เดิมว่า หลังจากที่ AI คิดคำตอบเสร็จแล้ว ให้ทำการเปิด `Session` ➔ ยัดข้อมูลลงตาราง (Add) ➔ บันทึก (Commit) ➔ ปิด `Session`
7. สร้าง Endpoint ใหม่ชื่อ **`/history`** แบบ GET เพื่อใช้ดึงประวัติ โค้ดจะสั่งให้ Database ค้นหาประวัติทั้งหมด แล้วเรียงจากใหม่สุดไปเก่าสุด (`order_by(desc)`) และดึงมาโชว์แค่ 10 รายการล่าสุด (`limit(10)`)
8. **ทดสอบระบบ:** ลองยิง `curl` เข้าไปถามคำถาม 3-4 ข้อ (เช่น ถามเรื่อง OSPF, VLAN, อินเทอร์เฟซดับ)
9. ลองยิง `curl` ไปที่ `/history` ระบบจะพ่นประวัติที่เราเพิ่งถามไปเมื่อกี้กลับมาให้ดูทั้งหมดอย่างสวยงาม

---

### **How it works… (เบื้องหลังการทำงานของโค้ด)**

หัวข้อนี้อธิบายถึงสิ่งที่เราเพิ่งทำไปกับ **SQLAlchemy (เครื่องมือช่วยเขียน Database):**

- `engine` : คือตัวกลางที่ต่อท่อไปยังไฟล์ฐานข้อมูล SQLite
- `Base` : คือคลาสแม่แบบที่เราเอาไว้ใช้สร้างตาราง
- `session` : คือตัวแทนจำหน่าย (Factory) ที่เราต้องเรียกใช้ทุกครั้งเวลาอยากจะบันทึกหรือดึงข้อมูล (เปิด-เซฟ-ปิด)

การใช้ ORM (Object-Relational Mapping) แบบนี้ ทำให้เราไม่ต้องเขียนภาษา SQL ยุ่งยากๆ เลย (เช่น `INSERT INTO...`) เราแค่จัดการมันเหมือนตัวแปร Python ธรรมดาๆ ตัวหนึ่ง

### **There’s more… (เทคนิคเพิ่มเติม)**

Database ไม่ได้มีดีแค่เก็บประวัติ แต่เราสามารถใช้คำสั่งทางสถิติของ SQLAlchemy (เช่น `func.count()`) มาสร้าง Endpoint ใหม่ชื่อ `/stats` เพื่อทำหน้าสรุปสถิติ (Dashboard) ได้ด้วย เช่น ดูว่า "ยอดรวมคำถามมีกี่ข้อ?" หรือ "คนชอบถามปัญหาเกี่ยวกับยี่ห้อไหนมากที่สุด? (Group by ยี่ห้อ)"
