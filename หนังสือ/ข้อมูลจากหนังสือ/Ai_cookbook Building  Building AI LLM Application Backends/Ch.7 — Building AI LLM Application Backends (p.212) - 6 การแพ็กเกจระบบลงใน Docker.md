### **7.5 Docker deployment (การแพ็กเกจระบบลงใน Docker)**

โค้ดที่เราเขียนมาทั้งหมดในบทนี้ตอนแรกมันรันอยู่แค่ในคอมพิวเตอร์ของเราเท่านั้น ในหัวข้อสุดท้ายนี้ เราจะมาทำการ "แพ็กเกจ (Package)" แอปพลิเคชัน Network AI ของเราใส่ลงใน **Docker Container** (เหมือนการจับระบบใส่ตู้คอนเทนเนอร์) เพื่อให้มันสามารถเอาไปรันที่ไหนก็ได้ในโลกโดยที่ระบบไม่พังครับ

### **Getting ready (เตรียมความพร้อม)**

ต้องเขียนหน้าเว็บเสร็จแล้ว และต้องมั่นใจว่าคอมพิวเตอร์ติดตั้งโปรแกรม Docker ไว้เรียบร้อยแล้ว

### **How to do it… (ขั้นตอนการทำ)**

1. **สร้างไฟล์ Dockerfile:** สร้างไฟล์ชื่อ `dockerfile` (ไม่มีนามสกุล) โดยระบุคำสั่งพื้นฐาน เช่น ให้ใช้ Python 3.11, ก๊อปปี้ไฟล์โค้ดเข้าไปในตู้, สั่งติดตั้งไลบรารี, และเปิดพอร์ต 8000 รอรับการเชื่อมต่อ
2. **แก้โค้ด Uvicorn เล็กน้อย:** **อันนี้สำคัญมาก!** ตอนรันบนคอมเราตั้งค่าไว้ที่ `localhost` แต่ตอนเอาลง Docker เราต้องแก้โค้ดบรรทัดสุดท้ายเป็น `host="0.0.0.0"` เพื่อให้ตู้คอนเทนเนอร์ยอมรับการเชื่อมต่อจากโลกภายนอก (ถ้าไม่แก้ พอร์ต 8000 จะถูกปิดตายอยู่แค่ในตู้)
3. **สร้างไฟล์ requirements.txt:** จดชื่อไลบรารีทั้งหมดที่ใช้ (fastapi, uvicorn, openai, sqlalchemy) ลงในไฟล์นี้ เพื่อให้ Docker รู้ว่าต้องโหลดอะไรบ้าง
4. **สร้างตู้ (Build):** พิมพ์คำสั่ง `$ docker build -t network-ai .` เพื่อเริ่มสร้างอิมเมจของตู้คอนเทนเนอร์
5. **รันตู้ (Run):** สั่งรันด้วย `$ docker run -p 8000:8000 -e OPENAI_API_KEY="ใส่กุญแจที่นี่" network-ai` _(หมายเหตุ: การโยน API Key เข้าไปผ่านคำสั่ง `-e` ทำให้เราไม่ต้องฝัง API Key ไว้ในโค้ด ปลอดภัยขึ้นไปอีกระดับ)_
6. ลองเปิดเบราว์เซอร์เข้าพอร์ต 8000 จะเห็นหน้าเว็บเดิมเป๊ะๆ แต่คราวนี้มันรันออกมาจากใน Docker แล้ว!
7. ลองทดสอบยิง `curl` เข้าไปถามคำสั่งตั้งค่า VLAN ของระบบที่อยู่ใน Docker ก็จะพบว่ามันทำงานและพ่น JSON กลับมาได้ตามปกติ


### **How it works… (เบื้องหลังการทำงาน)**

นี่คือรูปแบบมาตรฐาน (Standard Workflow) ของการทำซอฟต์แวร์ยุคใหม่เลยครับ: `เขียน Dockerfile ➔ เตรียมไฟล์ Requirements ➔ Build และ Run ตู้ ➔ ทดสอบ` ข้อดีขั้นสุดยอดคือ เมื่อมันกลายเป็นตู้คอนเทนเนอร์แล้ว คุณจะย้ายมันไปรันบน DigitalOcean, AWS, Azure, Google Cloud หรือเอาไปให้เพื่อนรันในเครื่องตัวเอง **ระบบก็จะทำงานได้เหมือนกันเป๊ะ 100% โดยไม่มีปัญหาจุกจิกเรื่อง "เวอร์ชันโปรแกรมไม่ตรงกัน" อีกต่อไป**

### **Summary (สรุปส่งท้ายบทที่ 7)**

ในบทนี้เราได้สร้าง Backend แบบเต็มรูปแบบที่ขับเคลื่อนด้วย AI พร้อมมีหน้าเว็บแอบแฝงนิดหน่อยให้ทีมใช้งานได้ แต่ในโลกของนักพัฒนา "งานไม่มีวันจบหรอกครับ" เพราะเราต้องคอยเพิ่มข้อมูลและลอจิกใหม่ๆ เข้าไปเสมอ ยิ่งเดี๋ยวนี้มี Framework ฝั่ง Frontend ใหม่ๆ ผุดขึ้นมาเป็นดอกเห็ด ยิ่งทำให้ฝั่ง Backend อย่างเราต้องคอยอัปเดตระบบตามไปด้วย
