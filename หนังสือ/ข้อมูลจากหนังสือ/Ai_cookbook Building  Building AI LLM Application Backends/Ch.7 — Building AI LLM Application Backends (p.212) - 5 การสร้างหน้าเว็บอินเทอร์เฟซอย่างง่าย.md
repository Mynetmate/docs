### **7.4 Simple web interface (การสร้างหน้าเว็บอินเทอร์เฟซอย่างง่าย)**

แม้ว่าหน้าที่หลักของ Backend จะมีไว้เพื่อจัดการลอจิกและข้อมูล (ไม่มีหน้าตา UI) แต่นั่นไม่ได้หมายความว่าเราจะสร้างหน้าเว็บง่ายๆ ฝังไว้ใน Backend ไม่ได้! ในหัวข้อนี้ เราจะมาสร้างหน้าเว็บ HTML แบบเรียบง่ายฝังไว้ในตัว FastAPI เลย เพื่อให้คนทั่วไปสามารถเข้ามาพิมพ์ถามคำถามกับ AI ได้บนเบราว์เซอร์ โดยไม่ต้องพึ่งคำสั่ง `curl` ที่ดูซับซ้อน

---

### **Getting ready (เตรียมความพร้อม)**

ต้องเขียนโค้ดเรื่องฐานข้อมูลจากหัวข้อที่แล้วให้เสร็จก่อน

---

### **How to do it… (ขั้นตอนการทำ)**

1. **อิมพอร์ตเครื่องมือทำเว็บ:** เรียกใช้งาน `Form` (เพื่อรับค่าจากฟอร์มหน้าเว็บ) และ `HTMLResponse` (เพื่อบอก FastAPI ว่าเราจะพ่นโค้ดหน้าเว็บกลับไปนะ ไม่ใช่ JSON)
2. **สร้างหน้าแรก (Home Page):** สร้าง Endpoint หน้าหลักที่ `/` แล้วเขียนโค้ดส่งคืนค่าเป็นแท็ก `<html>...</html>` สั้นๆ
3. **สร้างฟอร์มกรอกข้อมูล:** ในโค้ด HTML จะมีฟอร์มให้กรอก 2 ช่องคือ
    - ช่อง `textarea` สำหรับพิมพ์คำถาม
    - ช่อง `select (Dropdown)` สำหรับให้คลิกเลือกยี่ห้อ (Cisco, Juniper, ฯลฯ)
4. **สร้างหน้าแสดงคำตอบ:** สร้าง Endpoint หน้า `/web-ask` (รับค่าแบบ POST)
    - เมื่อ User กดปุ่ม Submit หน้าเว็บจะส่งข้อมูลคำถาม+ยี่ห้อ มาที่ฟังก์ชันนี้
    - ฟังก์ชันจะเอาไปส่งให้ AI ประมวลผล ➔ เซฟลง Database ➔ แล้วพ่นโค้ดหน้าเว็บ HTML อีกหน้าหนึ่งกลับไป เพื่อแสดงผลลัพธ์คำตอบสวยๆ
5. **ตกแต่งหน้าตา:** ผู้เขียนมีการแทรกแท็ก `<style>` (CSS พื้นฐาน) เอาไว้แต่งสีพื้นหลัง ทำกรอบข้อความ ให้พอดูสบายตาขึ้น
6. เมื่อรันโค้ดและเข้าเบราว์เซอร์ จะเห็นหน้าเว็บฟอร์มสีน้ำเงินๆ ให้กรอก
7. พอกดส่งคำถามไปปุ๊บ หน้าเว็บจะเปลี่ยนไปโชว์คำตอบของ AI ที่ถูกไฮไลต์ไว้ในกรอบ
8. ในหนังสือมีการแปะโค้ดฉบับเต็มไว้ให้ดู (ซึ่งค่อนข้างยาว เพราะเป็นการมัดรวมทั้งโค้ดเรียก AI + โค้ด Database + โค้ด API + โค้ด HTML ไว้ในไฟล์เดียวกันทั้งหมด)

---

### **How it works… (เบื้องหลังการทำงานของโค้ด)**

หัวข้อนี้ทำให้เราเห็นว่า ภายใต้สคริปต์ Python ไฟล์เดียว เราสามารถยัดความสามารถระดับเทพลงไปได้ครบทุกวงจรเลย ไม่ว่าจะเป็น การประมวลผล AI (LLM), การวาดหน้าเว็บ (HTML), การสร้างช่องทางเชื่อมต่อ (API) และการบันทึกลงฐานข้อมูล (Database) เรียกว่าเขียนไฟล์เดียวจบพร้อมใช้งาน!

---

### **There’s more… (เทคนิคเพิ่มเติม)**

ถ้าอยากให้หน้าเว็บดูโปรขึ้นอีกนิด เราสามารถแทรกแท็ก `<script>` (JavaScript) ลงไปที่ปุ่ม Submit ได้ เช่น สั่งว่า **"เมื่อ User กดปุ่ม ให้เปลี่ยนตัวหนังสือบนปุ่มเป็นคำว่า 'Thinking...' (กำลังคิด...) แล้วล็อคปุ่มไม่ให้กดซ้ำรัวๆ"** ระหว่างที่รอ AI ประมวลผลครับ
