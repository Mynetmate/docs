## สรุปสำหรับจดใน Obsidian

```
Applications of Component Diagram

1. System Design & Architecture
   → แสดงโครงสร้าง Component, interaction และ dependency

2. Requirements Analysis
   → เชื่อม Requirement กับส่วนต่าง ๆ ของระบบ

3. System Documentation
   → ใช้เป็นเอกสารอ้างอิง Architecture

4. Software Development
   → กำหนดขอบเขตและ responsibility ของแต่ละ Component

5. Code Generation & Implementation
   → ใช้เป็น Blueprint สำหรับสร้างโครงสร้าง Code

6. Maintenance & Evolution
   → วิเคราะห์ผลกระทบเมื่อแก้ไข เพิ่ม หรือขยายระบบ
```
