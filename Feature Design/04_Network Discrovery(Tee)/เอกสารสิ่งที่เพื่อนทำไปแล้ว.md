# สรุปความคืบหน้าของโปรเจกต์ Oxian (Network Discovery)
(อัปเดตล่าสุดจากการตรวจสอบซอร์สโค้ดในโฟลเดอร์ `oxian`)

**ภาพรวมโปรเจกต์:**
`oxian` เป็น CLI tool ที่พัฒนาด้วยภาษา **Rust** (Edition 2024) สำหรับใช้สแกนและค้นหาอุปกรณ์เครือข่ายอัตโนมัติ (Network Device Discovery) ผ่านโปรโตคอล SNMP (v2c) โดยเน้นไปที่การค้นหา Topology (แผนผังการเชื่อมต่อ) ของเครือข่าย

**เทคโนโลยีและไลบรารีหลักที่ใช้ (จาก `Cargo.toml`):**
- **Async Runtime:** `tokio`
- **SNMP Client:** `async-snmp`
- **CLI Parser:** `clap`
- **IP/Subnet Management:** `ipnet`

**ฟีเจอร์และโครงสร้างระบบที่พัฒนาไปแล้ว:**

1. **CLI Commands (`src/cli/`):**
   - รองรับคำสั่งหลักคือ `oxian scan <IP> [CIDR]` 
   - สามารถเลือกได้ว่าจะสแกน IP เดียวเพื่อหา Topology เชื่อมโยง หรือจะสแกนทั้งเครือข่ายด้วยการระบุ Subnet

2. **Network Scanner & Engine (`src/discovery/`):**
   - **Recursive Device Scanning (`engine.rs`):** หากระบุแค่ IP เดียว ระบบจะทำตัวเป็น BFS (Breadth-First Search) สแกนอุปกรณ์เริ่มต้น แล้วดึงข้อมูล Neighbor IPs มาเข้าคิวสแกนต่อ เพื่อให้ค้นหาอุปกรณ์ในระบบเครือข่ายได้ลึกขึ้น
   - **Device Enumeration (`scanner.rs`):** เมื่อสแกนอุปกรณ์แต่ละตัว จะดึงข้อมูลสำคัญ ได้แก่ System Info (sysName, sysDescr), ข้อมูล Interface, Local Chassis ID, ตาราง Neighbors (ผ่าน LLDP/CDP), และ Default Route
   - **Topology Resolution (`topology.rs`):** นำข้อมูลที่กระจัดกระจายมาประกอบร่างเป็น Topology (`DiscoveryResult`) โดยมีลอจิกจับคู่ความสัมพันธ์ของ Link (ใครต่อกับใคร พอร์ตไหน) และสามารถอนุมานอุปกรณ์ปลายทางที่สแกนไม่เข้า (Unresolved Neighbors/Default Gateway) ได้ด้วย

3. **SNMP Operations (`src/snmp/`):**
   - ตั้งค่าการเชื่อมต่อด้วย SNMP v2c แบบ Hardcode ค่า Community String ไว้ที่ `"public"` และ Timeout 5 วินาที
   - แบ่งโมดูลการดึง OID ชัดเจน: `system.rs` (ดึง Hostname, Description, OID), `interface.rs`, `neighbors.rs`, และ `route.rs`

4. **Vendor Detection (`src/vendor/`):**
   - มีระบบจำแนกยี่ห้อ (Vendor) จาก `sysObjectID`
   - ปัจจุบันรองรับการตรวจจับ **Cisco** (OID ขึ้นต้นด้วย `1.3.6.1.4.1.9`) และ **MikroTik** (OID ขึ้นต้นด้วย `1.3.6.1.4.1.14988`) ซึ่งสอดคล้องกับ Scope ของโปรเจกต์ MyNetMate
