## 💡 สิ่งที่ Tab นี้เฉลยให้

### 1. ✅ ยืนยันว่า Template-first คือทางถูก

Config ที่ออกมา **ไม่ได้ใช้ AI เลยแม้แต่นิดเดียว** — มันมาจาก **Jinja2 Template ล้วนๆ** ที่รับข้อมูลจาก Form แล้ว Render ออกมา ตรงกับที่อาจารย์บอกว่า:

> _"Rule-based/Template เป็นแกนหลัก AI เป็นแค่ผู้ช่วย"_

### 2. ✅ CIS Benchmarks บางข้อ ระบบใส่ให้อัตโนมัติเลย

สังเกตว่า Services Tab มีแค่ Checkbox แต่ Config ออกมาเป็น:

|Checkbox ที่กด|Config ที่ Generate|
|---|---|
|✅ SSH v2|`crypto key generate rsa modulus 2048` + `ip ssh version 2`|
|❌ Telnet|`no service telnet`|
|❌ HTTP|`no ip http server`|
|✅ HTTPS|`ip http secure-server`|
|✅ LLDP|`lldp run`|

= นี่คือ **CIS Benchmark Rule-based** ที่ทำได้โดยไม่ต้องใช้ AI เลย! เขียน Template ครั้งเดียวจบ

### 3. ✅ Jinja2 Template Structure ที่ต้องเขียน

เห็นชัดเลยว่า Template จะหน้าตาประมาณนี้:

```
```jinja2

! Generated by SkaiNet

! Vendor: {{ device.vendor }}

!

hostname {{ device.hostname }}

service password-encryption

!

{% if services.ssh_v2 %}

crypto key generate rsa modulus 2048

ip ssh version 2

{% endif %}

{% if not services.telnet %}

no service telnet

{% endif %}

{% if not services.http %}

no ip http server

{% endif %}

{% if services.https %}

ip http secure-server

{% endif %}

{% if services.lldp %}

lldp run

{% endif %}

!

{% for vlan in vlans %}

vlan {{ vlan.id }}

 name {{ vlan.name }}

{% if vlan.svi_ip %}

!

interface Vlan{{ vlan.id }}

 description SVI-{{ vlan.name }}

 ip address {{ vlan.svi_ip }}

 no shutdown

{% endif %}

!

{% endfor %}

{% for iface in interfaces %}

interface {{ iface.name }}

 description {{ iface.description }}

{% if iface.mode == 'trunk' %}

 switchport mode trunk

 switchport trunk encapsulation dot1q

{% elif iface.mode == 'access' %}

 switchport mode access

{% endif %}

 no shutdown

!

{% endfor %}

end
```

### 4. ✅ "Ask Claude to review" = จุดที่ AI เข้ามา

ปุ่มนี้คือ **AI Layer** ที่อาจารย์พูดถึง:

Form → Jinja2 Template → Config Preview

                                ↓

                    [Copy config] → ใช้งานเลย

                    [Ask AI to review] → PII Mask → Gemini → Security Feedback
