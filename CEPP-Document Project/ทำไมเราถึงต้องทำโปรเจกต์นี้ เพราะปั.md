หน้า 1: ปก 
"สวัสดีคณะกรรมการทุกท่านครับ พวกผมกลุ่ม CEPP-33 จะมานำเสนอรายงานข้อเสนอ
 ในหัวข้อ แอปพลิเคชันสำหรับการบริหารเครือข่ายและการกำหนดค่าเครือข่ายอัตโนมัติ

หน้า 2: ทีมงาน 
"สำหรับสมาชิกในทีม 4 คน ประกอบด้วย ผม นายนภัทร นายจารุเดช, นายฉัตรนรินทร และนายธนพนจ์ 
โดยมี อาจารย์ ปริญญา เอกปริญญา เป็นอาจารย์ที่ปรึกษาโครงงานครับ"

หน้า 3: สารบัญ 
"ในการนำเสนอวันนี้ เราจะไล่เรียงตั้งแต่ ที่มาและความสำคัญ, กลุ่มStakeholder ปัญหาที่พบในปัจจุบัน,  
Workflow ของระบบงานเก่า หากใช้ระบบใหม่เราจะเป็นอย่างไร, รายละเอียดการออกแบบระบบโดยรวม และจบที่แผนการดำเนินงานครับ"

หน้า 4: 
 "เรามาเริ่มกันที่ส่วนแรก คือ ที่มาและบริบทความสำคัญของโครงการ"

หน้า 5: บทนำ 
ในปัจจุบัน องค์กรทุกขนาดมีการขยายตัวทางดิจิตอลอย่างรวดเร็ว 
ทำให้อุปกรณ์เครือข่ายมีปริมาณเพิ่มสูงขึ้นอย่างมาก ส่งผลให้ภาระงานในการบริหารจัดการและการ Config อุปกรณ์ 
กลายเป็นเรื่อง ที่ซับซ้อนและต้องใช้ระยะเวลาสูงมากอย่างหลีกเลี่ยงไม่ได้ครับ"

หน้า 6: ข้อมูลสถิติ 
จากกราฟจะเห็นว่าร้อยละ 60 ของการเปลี่ยนค่าคอนฟิกยังใช้การ Manual
ซึ่งจากเว็บไซต์ บริษัทวิจัยและที่ปรึกษาด้านเทคโนโลยี Gartner ยืนยันว่าการ Config แบบเดิม คือสิ่งที่ ทำให้เกิด Human Error ครับ 
และ งานวิจัยล่าสุดในปี 2025 
ยังชี้ให้เห็นว่า เวลาของผู้แลเครือข่ายเกือบ 40% เสียไปกับ Troubleshooting แทนที่จะเอาเวลาไปออกแบบระบบให้ดีขึ้น 
เพาะฉะนั้นระบบ Automation ของเราจึงเกิดมาแก้ไขปัญหาเหล่านี้ครับ

หน้า 7: 02. ผู้มีส่วนได้ส่วนเสีย 
เพื่อให้เข้าใจปัญหาอย่างแท้จริง เราได้วิเคราะห์ Stakeholders ที่เกี่ยวข้องครับ"

หน้า 8: กลุ่ม Stakeholders 
เราได้Stakeholders หลักออกมาเป็น 3 กลุ่มครับ คือ
ผู้ดูแลระบบ IT 
พนักงานบำรุงรักษาเครือข่าย 
แลผู้ดูแลศูนย์ข้อมูล 

หน้า 9: เสียงจากลูกค้า 
"จากการที่เราได้ลงพื้นที่สัมภาษณ์ เราพบเสียงจากลูกค้าว่า
การนั่ง Config ต้องนั่งแก้ทีละเครื่องโดยใช้ SSH  ซึ่งมันเสียเวลา
และ พนักงานใหม่เข้ามาต้องมานั่งงมเข้าใจระบบใหม่ เพราะผังระบบ และเอกสารที่มีมันล้าสมัย
และมีก็กังวลว่า 'ถ้ามีการ Config ผิดพลาดทำให้เกิดผลกระทบ' และ ไม่มีระบบย้อนกลับค่าเดิมที่เชื่อถือได้
